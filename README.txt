Как получить APK (нужен бесплатный аккаунт на github.com, проще с компьютера):
1. Создай новый репозиторий и загрузи в него всё содержимое архива, включая скрытую папку .github.
2. Открой вкладку Actions. Сборка запустится сама (или нажми Run workflow у "Build APK").
3. Через 3-5 минут открой завершённый запуск, внизу в Artifacts скачай vybivalka-apk. Внутри app-debug.apk.
4. Перекинь файл на телефон и установи (Android попросит разрешить установку из неизвестных источников).
